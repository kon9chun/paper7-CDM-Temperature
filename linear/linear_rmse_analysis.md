- **文件**：`linear_rmse.npy`
- **含义**：插值重构结果与真值之间的 RMSE（均方根误差）
- **样本数量**：10000 个

## 3. 误差特征分析

### 3.1 整体评价

- **均值（0.0269）大于中位数（0.0204）**，说明存在少量较大误差样本拉高了平均值，分布呈**右偏态**。
- **86.7%** 的样本 RMSE < 0.05，插值效果较好。
- **99%** 的样本 RMSE < 0.13，最大误差不超过 0.181。

### 3.2 误差分布特点

```
        低误差区 (RMSE < 0.01)     : 16.2%
        中等误差区 (0.01-0.05)     : 56.2%
        较高误差区 (0.05-0.10)     : 11.9%
        高误差区 (RMSE > 0.10)     : 2.5%
```

### 3.3 误差来源分析

1. **真值并非完全线性**：线性插值假设数据在已知点之间呈线性变化，但真实数据可能存在非线性特征。
2. **稀疏采样**：仅用 9 个点（采样率约 0.94%）重建 9600 个点，高误差样本可能对应真值非线性程度较高的区域。
3. **边界效应**：角落和边缘区域只有单个方向有约束，插值精度较低。

## 5. 结论

| 评估项 | 结论 |
|--------|------|
| 整体误差水平 | **低**（均值 0.027，相对于数据范围 ~300 约为 0.009%） |
| 误差稳定性 | **较好**（86.7% 样本 RMSE < 0.05） |
| 极端误差 | **较少**（仅 2.5% 样本 RMSE > 0.10） |
| 插值适用性 | **基本适用**，但对非线性较强的数据需考虑更高阶插值方法 |

## 6. 改进建议

若需降低 RMSE，可考虑：
1. **双三次插值（bicubic）**：对非线性区域拟合更好
2. **薄板样条（Thin Plate Spline）**：适合散点数据的平滑插值
3. **增加采样点密度**：提高原始稀疏网格的分辨率
